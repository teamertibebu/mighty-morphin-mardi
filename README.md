# Mighty Morphin Mardi

Morphin’ Mardi is a playful AI image editing app that remixes photos of my dog, Mardi, from user prompts. 
I’m building it to grow my Python and FastAPI skills and to get more hands-on experience building with AI tooling.

## Tech Stack

- **_Python_** for the core application logic.
- **_FastAPI_** for the backend API and server-side functionality.
- _**React**_ for the frontend UI and client-side interactivity.
- **_OpenAI API_** for AI-powered image editing.
